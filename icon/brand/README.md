# GuineaNote official asset exports
All mascot files in this package are derived from a single cropped extraction of the **selected bottom-right pixel guinea pig + terminal concept** in the original design sheet. No AI re-generation or manual redrawing was used for individual variants.

- Master: `png/guineanote-master-transparent.png`
- SVG: `svg/guineanote-master.svg` (SVG container embedding the master raster; **not native editable vector paths**)
- Windows icon: `ico/guineanote.ico`
- Favicon: `ico/favicon.ico`
- Horizontal: `png/guineanote-horizontal-dark.png`, `...-light.png`
- README banner: `banner/guineanote-readme-1600x500.png`
- Color palette: #0B1320 #153A34 #22C55E #86EFAC #FFF7E6 #C97A45 #F5D9C4 #FF9E9E

Note: background extraction from an existing concept image may leave minor edge artifacts; it is not an original layered/vector design.
