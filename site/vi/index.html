Notepad++ ngay trong terminal.

Guinea Note là trình soạn thảo văn bản miễn phí, mã nguồn mở cho terminal, viết bằng Rust. Có tab, một bảng Tìm/Thay thế dùng biểu thức chính quy, công cụ dòng, khôi phục phiên — và lưu file giữ nguyên từng byte như ban đầu.

> npx guinea-note notes.md

Ảnh chụp trình soạn thảo thật, giao diện tiếng Việt.

Cài đặt

Chạy được sau một phút.

Chọn cách cài phù hợp. Cách nào cũng chạy đúng file như trên GitHub Release (cùng SHA-256), và không cách nào cần Rust.

npm / npx Windows x64

Nếu máy có Node.js, npm sẽ tải bản native của trình soạn thảo về cho bạn. Không biên dịch gì trên máy.

  1. Kiểm tra Node.js là bản 18 trở lên 
    > node --version

    Chưa có Node.js? Dùng bản .zip cho Windows — không cần cài thêm gì.

  2. Chạy thử một lần, không cần cài 
    > npx guinea-note notes.md
  3. Hoặc cài hẳn lệnh guinea 
    > npm install -g guinea-note
> guinea notes.md

Bạn dùng Mac? Guinea Note chưa phát hành cho macOS. Bản phát hành chỉ dành cho Windows x64 và Linux x64.

Windows .zip portable

Một thư mục có sẵn guinea.exe. Không có trình cài đặt, không cần quyền quản trị, không cần Visual C++ runtime.

  1. Tải file nén (PowerShell), hoặc tải bằng trình duyệt 
    PS> Invoke-WebRequest https://github.com/cmm-cmm/GuineaNote/releases/download/v0.1.3/guinea-0.1.3-x86_64-pc-windows-msvc.zip -OutFile guinea.zip
  2. Kiểm tra SHA-256 — kết quả phải là True 
    PS> Invoke-WebRequest https://github.com/cmm-cmm/GuineaNote/releases/download/v0.1.3/SHA256SUMS -OutFile SHA256SUMS
PS> (Get-FileHash guinea.zip -Algorithm SHA256).Hash -eq ((Select-String windows-msvc.zip SHA256SUMS).Line -split ' ')[0]
  3. Giải nén 
    PS> Expand-Archive guinea.zip -DestinationPath "$env:LOCALAPPDATA\GuineaNote"
  4. Thêm vào PATH (chỉ cho người dùng hiện tại) 
    PS> [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";$env:LOCALAPPDATA\GuineaNote\guinea-0.1.3-x86_64-pc-windows-msvc", "User")

    Sau đó mở cửa sổ terminal mới để nhận PATH mới.

  5. Bắt đầu soạn thảo 
    PS> guinea notes.md

Linux x64 file chạy tĩnh

Một file chạy tĩnh (musl) dùng được trên mọi bản phân phối x64, không phụ thuộc thư viện nào.

  1. Tải file nén và checksum 
    $ curl -LO https://github.com/cmm-cmm/GuineaNote/releases/download/v0.1.1/guinea-0.1.1-x86_64-unknown-linux-musl.tar.gz
$ curl -LO https://github.com/cmm-cmm/GuineaNote/releases/download/v0.1.1/SHA256SUMS
  2. Kiểm tra — dòng kết quả phải kết thúc bằng OK 
    $ sha256sum --ignore-missing -c SHA256SUMS
  3. Giải nén và cài 
    $ tar -xzf guinea-0.1.1-x86_64-unknown-linux-musl.tar.gz
$ install -m 755 guinea-0.1.1-x86_64-unknown-linux-musl/guinea ~/.local/bin/

    Nếu sau đó không tìm thấy lệnh guinea, hãy thêm ~/.local/bin vào PATH.

  4. Bắt đầu soạn thảo 
    $ guinea notes.md

Linux đang ở bản 0.1.1. Bản 0.1.2 và 0.1.3 chỉ phát hành cho Windows trong lúc tạm dừng kiểm tra bản build Linux; bản Linux sẽ được cập nhật khi việc kiểm tra chạy lại.

Cargo build từ mã nguồn

Bắt đầu nhanh

Mở. Sửa. Lưu.

Nếu đã dùng Notepad++, bạn gần như biết hết rồi. Không có mode: cứ gõ, và các phím quen thuộc làm đúng việc quen thuộc.

01

Mở file

Đường dẫn chưa tồn tại sẽ được tạo khi lưu. Nhiều file mở thành nhiều tab, và gõ guinea không kèm gì sẽ mở lại phiên trước.

$ guinea notes.md
02

Sửa như Notepad++

Ctrl+S để lưu, Ctrl+F để tìm, Ctrl+Z để hoàn tác, Ctrl+D để nhân đôi dòng. BOM và kiểu xuống dòng được giữ nguyên.

03

Tìm mọi thao tác

F2 liệt kê mọi thao tác kèm phím tắt — hoặc lý do thao tác chưa dùng được lúc này. F1 mở hướng dẫn phím và Ctrl+Q để thoát.

Xem nhanh

Màn hình thật, không phải ảnh dựng.

Mọi ảnh đều chụp từ trình soạn thảo đang chạy trong terminal.

Tính năng

Bộ công cụ của Notepad++, trong terminal.

Nhanh với file lớn, cẩn thận với từng byte, và mọi thao tác đều làm được bằng bàn phím.

Tab và khôi phục phiên

Thanh tab một dòng, trình quản lý tab (F12 / Ctrl+P) để lọc, chuyển, lưu và đóng tab; lần mở sau tự mở lại file, vị trí con trỏ và tab đang chọn.

Tìm/Thay thế bằng regex

Một bảng cho cả hai, biểu thức chính quy thời gian tuyến tính, thay thế $1 / ${name}, đánh dấu tất cả. Thay tất cả là một bước Hoàn tác.

Công cụ dòng và chữ

Sắp xếp, xóa dòng trùng hoặc dòng trống, cắt khoảng trắng cuối dòng, đổi HOA / thường / Hoa Đầu Từ, comment dòng, di chuyển và nhân đôi dòng.

Giữ nguyên từng byte

UTF-8 chặt chẽ, giữ nguyên BOM và kiểu xuống dòng LF / CRLF / hỗn hợp. Lưu nguyên tử, báo xung đột khi chương trình khác đã sửa file; encoding không hợp lệ, file nhị phân và symlink bị từ chối thay vì bị làm hỏng.

Khôi phục sau sự cố

Tab chưa lưu được ghi lại khoảng mỗi giây vào kho riêng và quay lại dưới dạng bản nháp sau khi chương trình bị tắt đột ngột.

Xem trước dễ đọc

Markdown, JSON, CSV/TSV, XML, TOML, YAML, INI/ENV và notebook, xem song song hoặc trong tab chỉ đọc liên kết (F8).

Nhanh với file lớn

Dòng dài và công cụ nặng chạy nền; phím gõ trong lúc đó được xếp hàng, không bị mất. Mọi thao tác trên 50 ms đều được điều tra trước khi phát hành.

Bàn phím là chính

Mọi thao tác chuột đều có phím tương ứng, và nhãn phím trên màn hình lấy từ chính bảng phím. Chuột là tùy chọn.

Tiếng Việt và English

Toàn bộ giao diện có hai ngôn ngữ: --language vi, hoặc Cài đặt F10 — lựa chọn được ghi nhớ.

Agent khi bạn cho phép

JSON CLI và MCP server cho coding agent cục bộ đọc và sửa tài liệu đang mở — chỉ khi bạn mở bằng --agent.

Guinea Note là gì?

Guinea Note là trình soạn thảo văn bản miễn phí, mã nguồn mở cho terminal, viết bằng Rust. Cách dùng giống Notepad++: tab, một bảng Tìm/Thay thế có biểu thức chính quy, công cụ dòng, bookmark và khôi phục phiên, không có chế độ (mode) phải học. Lệnh chạy là guinea.

Cài Guinea Note trên Windows thế nào?

Nếu có Node.js 18 trở lên, chạy npx guinea-note notes.md, hoặc npm install -g guinea-note để có lệnh guinea. Nếu không có Node.js, tải guinea-0.1.3-x86_64-pc-windows-msvc.zip từ GitHub Releases, kiểm tra SHA-256, giải nén và thêm thư mục vào PATH (xem từng bước). Gói winget cmm-cmm.GuineaNote đang chờ duyệt.

Cài Guinea Note trên Linux thế nào?

Tải guinea-0.1.1-x86_64-unknown-linux-musl.tar.gz và SHA256SUMS từ GitHub Releases, kiểm tra bằng sha256sum --ignore-missing -c SHA256SUMS, giải nén rồi chép guinea vào ~/.local/bin (xem từng bước). File chạy tĩnh này chạy trên Debian 11 và 12, Ubuntu 22.04, Alpine 3.20 và các bản phân phối x64 khác. Bản 0.1.2 và 0.1.3 chỉ phát hành cho Windows nên Linux tạm dùng 0.1.1.

Có cần cài Rust hay Node.js không?

Không. Các bản phát hành là file chạy native độc lập. Chỉ cần Node.js 18 trở lên nếu cài qua npm, và Rust 1.98 trở lên nếu tự build từ mã nguồn bằng cargo install.

Guinea Note có miễn phí không?

Có. Guinea Note miễn phí và là mã nguồn mở theo giấy phép MIT. Mã nguồn ở GitHub: github.com/cmm-cmm/GuineaNote.

Guinea Note có đổi encoding hay kiểu xuống dòng của file không?

Không. Guinea Note sửa file UTF-8 và giữ nguyên BOM cùng kiểu xuống dòng LF, CRLF hoặc hỗn hợp; các byte bạn không sửa được lưu y như cũ. Lưu file là thao tác nguyên tử và dừng lại báo xung đột nếu chương trình khác đã sửa file. File encoding khác, file nhị phân và symlink bị từ chối thay vì bị làm hỏng.

Guinea Note khác Nano hay Vim ở điểm nào?

Guinea Note không có chế độ (mode): bạn gõ chữ trực tiếp và dùng các phím quen thuộc như Ctrl+S, Ctrl+F, Ctrl+Z, Ctrl+Q. Nó học theo Notepad++ chứ không theo Nano hay Vim, với tab, bảng Tìm/Thay thế và công cụ dòng. F2 liệt kê mọi thao tác kèm phím tắt.

Guinea Note có chạy trên macOS không?

Không. Bản phát hành chỉ dành cho Windows x64 và Linux x64; macOS không được phát hành và không được kiểm thử.

Dùng Guinea Note bằng tiếng Việt được không?

Được. Giao diện có tiếng Việt và tiếng Anh. Mở bằng guinea --language vi, hoặc đổi ngôn ngữ trong Cài đặt (F10); lựa chọn được ghi nhớ.

AI coding agent có dùng được Guinea Note không?

Có, nếu bạn cho phép. Mở trình soạn thảo với --agent để agent cục bộ đọc tài liệu đang mở qua JSON CLI guineanote-agent hoặc MCP server guineanote-mcp; thêm --agent-write để cho phép sửa và lưu. Mặc định tính năng này tắt, và các đường dẫn nhạy cảm như .env vẫn bị chặn trừ khi bạn cho phép.
